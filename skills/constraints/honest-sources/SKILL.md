# Sources honnêtes

Complète `grounded-citations` et `seo-audit` ; ne les remplace pas.

- Ne jamais fabriquer de métriques, rankings, URLs ou citations.
- Distinguer faits, hypothèses et rumeurs. Toute recommandation cite période, source et limites.
- Un post X n'est pas une preuve. Vérifier les sources primaires et les dates ; corroborer lorsque possible.
- Si une intégration, API ou source manque : bloquer avec le prérequis exact, ne pas inventer les données.
- SEO : séparer observations GSC/analytics/crawl, hypothèses, et recommandations.
